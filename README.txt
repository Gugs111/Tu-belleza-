TU BELLEZA — V9

CAMBIOS DE VENTAS
- En Inventario, el botón ahora dice “✓ Vendido”.
- Cada toque en “✓ Vendido” descuenta 1 unidad y registra automáticamente una venta con el precio del producto.
- La pestaña Ventas muestra el dinero acumulado y las ventas registradas.
- En Administrar > Ventas puedes agregar, editar o eliminar ventas.
- Al editar una venta puedes cambiar concepto, tipo, total, cliente y fecha.
- El total de “Ventas” que aparece en Inicio se calcula automáticamente con las ventas registradas, así que al editar/eliminar una venta también cambia ese total.
